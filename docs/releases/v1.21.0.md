# v1.21.0 — Enterprise AI development economics

Released 2026-07-25.

## What changed

- Added a standard-library-only AI FinOps semantic layer for native Claude
  Code OpenTelemetry and the existing JSONL-forwarder schema.
- Added effective-dated public API pricing for input, output, cache-read,
  cache-creation, long-context, supported fast mode, and chargeable server-tool usage. Reported
  approximate cost and calculated API-equivalent cost remain separate;
  unknown models are never assigned a fallback price.
- Added the `berserk-claude` launcher for governed team, portfolio, project,
  feature, work-item, repository, branch, agent, harness, and recommendation
  context.
- Added validated CSV/NDJSON feature-catalog and developer-effort imports,
  atomic private storage, and optional privacy-safe `engineering-work` OTLP
  emission.
- Added deterministic attribution with explicit feature/work-item, PR,
  branch, repository/project, and unattributed precedence. Ambiguous mappings
  are not split or guessed.
- Added nine Claude-lane MCP tools for spend, feature/project economics,
  efficiency findings, harness recommendations and approval, matched impact,
  management reports, and generated dashboard snapshots.
- Added operational, daily, and weekly headless agent-report modes with an
  optional schema-versioned JSON envelope.
- Added atomic CSV/NDJSON BI export with seven stable datasets and a checksum
  manifest.
- Added five Grafana dashboards and a bounded Berserk Explore query pack.

## Governance and safety

- Prompts, source code, raw commands, session bodies, and user email are not
  part of the FinOps model or generated outputs.
- Developer hours come only from the governed effort feed. They are never
  inferred from Claude active time or elapsed session time.
- Dashboard files can only be written beneath `BERSERK_MCP_REPORT_DIR`.
- Non-loopback OTLP endpoints must use HTTPS.
- Harness changes remain advisory. Decisions are append-only and owner and
  rationale values are hashed before local persistence or OTLP emission.
- Optimization impact requires minimum matched before/after cohorts by model
  and operation before issuing a keep or rollback verdict.

## Compatibility

The existing Claude tools and legacy telemetry attributes remain supported.
The package remains zero-dependency and MCP protocol `2025-06-18` compatible.
See [Claude Code telemetry](../claude-code.md) and the
[dashboard guide](../../dashboards/README.md) for operating instructions.

Live homelab verification also hardened the aggregate for Berserk's sparse
dynamic records: optional attributes are read through `$raw`, null numeric
values are string-normalized before conversion, wildcard `arg_max` is avoided,
epoch-nanosecond timestamps are normalized for effective-dated pricing, and an
unknown model version cannot inherit a generic family price.

The release was verified with 465 repository tests plus a clean wheel build,
isolated wheel install, console-entry-point checks, and packaged dashboard and
pricing-catalog inspection.
