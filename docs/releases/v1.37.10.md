# v1.37.10 — result envelope for saved queries

Released: 2026-11-17

`run_saved` and the `saved__<name>` tools returned the raw fenced rows. The
built-in tools already add a header with the window, row count and source. This
release gives saved queries the same header, so a small model can see where an
answer came from and whether an empty result means anything.

## What changed

- **Shared header.** `_envelope_header` in `berserk_mcp/tools.py` builds the
  one-line header. `_envelope` now calls it, and its output for the built-in
  tools is byte-identical. Saved results call it with `source=saved:<name>` and
  `ref=saved__<name>#<digest>`. The name is the sanitised saved name. The ref
  hashes the rows as the client receives them, after the output filter.
- **Extra fields.** `origin=manual` or `origin=generated`. A generated entry
  also shows `review=approved` when its status is `approved`, and
  `review=pending` otherwise. An entry saved with `allow_empty=true` shows
  `rows_verified=false`.
- **Layout.** The schema-drift warning, if any, comes first. Then the header,
  a blank line, and the fenced rows. The header holds server text only and no
  description text. The output limit and the fence are unchanged.
- **Empty results.** When the result has zero rows, the output is
  `No rows in window <since>.` and one more sentence. For an entry that never
  returned rows: `This saved query has never been seen returning rows; do not
  treat an empty result as a clean answer.` Otherwise: `Try since='24h ago'.`
  A saved `count()` that returns 0 is an answer and appears as normal.
- **Switch.** `BERSERK_MCP_ENVELOPE=0` restores the earlier output: the drift
  warning and the fenced rows.
- **Errors.** The error path is unchanged and stays fenced.

## Compatibility

Callers that parse saved output now see a header line before the fenced rows.
Set `BERSERK_MCP_ENVELOPE=0` to keep the old shape.

## Verification

New tests are in `tests/test_saved_query_envelope.py`. `run_saved` and the
`saved__*` dispatch use one function, and a test pins identical output.
