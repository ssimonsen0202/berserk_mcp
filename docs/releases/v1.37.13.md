# v1.37.13 — saved queries are findable in every mode

Released: 2026-11-17

## What changed

- **The gap.** In discovery mode, `tools/list` held only the anchor tools. It
  dropped every `saved__*` tool. `find_tool` searched built-in tools only. A
  saved query was reachable through the `list_saved` text and nothing else.
- **`find_tool` searches saved queries.** It ranks the built-in tools and every
  saved query that `config.item_visible` accepts for the active role and tier.
  It no longer stops at the 25 tools that `tools/list` projects.
- **Same tool as `tools/list`.** A saved candidate is the tool that
  `_saved_query_tools` projects for that entry: the same fenced description and
  the same `since` schema. Both paths call one function. The search text is
  never shown.
- **Index cache.** The combined index is cached. The key is the store path,
  the file's `(mtime_ns, size)`, the active role and the active tier. A change
  to any of them rebuilds the index. A missing or corrupt store falls back to
  the built-in tools.
- **Fixed word weights.** `tool_discovery.search` takes an optional
  `weights_from` index. Word weights then use the built-in tools' document
  frequencies and tool count only. Saved entries never change a built-in tool's
  score. A word found only in saved entries gets df=0 with the same smoothing.
- **Ranking guard.** At most two of the five candidates are saved queries when
  a built-in tool matched. On an equal score, a built-in tool ranks first. When
  no built-in tool matched, saved queries may fill all five places. A saved
  description stuffed with keywords therefore cannot push built-in tools out.
- **Discovery mode.** `tools/list` returns the anchors plus up to
  `BERSERK_MCP_DISCOVERY_SAVED_CAP` saved tools, most recent first. The default
  is `5`. `0` lists none. A non-numeric or negative value gives the default.
  Outside discovery mode, nothing changes.
- **`list_saved(query=...)`.** The new optional argument takes up to 200
  characters. It ranks entries with the same index and returns the ten best.
  Without it, `list_saved` lists every visible entry as before.
- **Descriptions.** `find_tool` no longer reads as a discovery-mode tool. It
  finds built-in and saved tools in every mode.
- **Unchanged.** `saved__*` dispatch, `run_saved`, locking and the store format.
  No new dependency and no new outbound call.

## Configuration

`BERSERK_MCP_DISCOVERY_SAVED_CAP` is new. See `docs/configuration.md`.

## Verification

`tests/test_tool_discovery_saved.py` holds the WP2 tests. Each failed before the
change. `tests/test_tool_discovery.py` adds a recall check with a 500-entry store.
