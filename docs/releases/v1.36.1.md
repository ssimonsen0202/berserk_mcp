# v1.36.1 — Current Claude prices

Released: 2026-10-02

`pricing_catalog.json` is now `anthropic-public-2026-10-02`. The prices come
from https://platform.claude.com/docs/en/about-claude/pricing.md, read on
2026-10-02.

## What was wrong

- The catalog had no entry for Claude Opus 5.5, Opus 5, Sonnet 5.5, Fable 5.1,
  or Mythos 5.1. `claude_spend_overview` priced their usage at $0 and
  reported low pricing coverage. In one 24-hour sample, Opus 5.5 was 94% of
  the tokens, and pricing coverage was 6.5%.
- `claude-sonnet-5-5` matched the `claude-sonnet-5` entry, because the
  catalog matches the longest alias that the model name contains.
- The `claude-sonnet-5` entry charged $3/$15 from 2026-09-01. That increase
  was cancelled. The pricing page says that $2/$10 is now the standard price.

## What changed

New entries ($/MTok: input, output, cache read, 5m write, 1h write):

| Model | Prices | Fast mode |
|---|---|---|
| `claude-opus-5-5` | 4, 20, 0.20, 5, 8 | 8, 40, 0.40, 10, 16 |
| `claude-opus-5` | 5, 25, 0.50, 6.25, 10 | 10, 50, 1, 12.50, 20 |
| `claude-sonnet-5-5` | 2, 10, 0.20, 2.50, 4 | — |
| `claude-fable-5-1` | 10, 50, 0.25, 12.50, 20 | — |
| `claude-mythos-5-1` | 10, 50, 0.25, 12.50, 20 | — |

`claude-sonnet-5` from 2026-09-01 is now 2, 10, 0.20, 2.50, 4.

The pricing page gives fast-mode input and output prices only. It says that
the caching multipliers apply on top of fast-mode prices, so the fast-mode
cache prices above are calculated from those multipliers.

## Tests

- `test_current_models_match_the_public_price_page` checks each current
  model against the prices copied from the pricing page.
- `test_opus_5_x_fast_mode_rates` checks the fast-mode prices.
- The Sonnet 5 test now expects $2/$10 from 2026-09-01.
- `test_unknown_version_does_not_match_generic_family_alias` used
  `claude-opus-5` as its unknown model. It now uses `claude-opus-9`, because
  `claude-opus-5` has an entry.

## Related fix outside this repo

The Claude Code log forwarder sent only input and output tokens. It now also
sends cache reads, cache writes (with the 1h part), web-search requests, and
`speed`, under the attribute names that `ai_finops.py` reads. Cache reads are
most of Claude Code's cost. Data that Berserk received before this fix has no
cache tokens.
